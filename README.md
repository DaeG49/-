# 프로젝트 이름
통화 차단 상황 시뮬레이터

## 프로젝트 소개

이 프로젝트는 전화번호가 차단된 상황에서 발신자가 상대방의 차단 여부를 쉽게 인지할 수 있는 문제에 대한 관심에서 시작했습니다.

일반적인 전화 차단 상황에서는 통화음이 짧게 들린 후 음성사서함으로 연결되는 등, 발신자가 상대방에게 차단되었다는 느낌을 받을 수 있습니다.

본 프로젝트에서는 실제 통신망이나 전화 기능을 직접 변경하지 않고, 가상의 통화 환경을 시뮬레이션하는 프로그램을 제작하여 다양한 통화 연결 상황을 구현하고자 합니다.

특히 차단 상황에서도 일정 횟수 동안 일반적인 통화음이 반복된 후 음성사서함으로 연결되는 형태를 구현하고, 이러한 방식이 기존의 차단 상황과 어떻게 다르게 인식되는지 확인하는 것을 목표로 합니다.
