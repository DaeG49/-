# 프로젝트 이름
통화 차단 상황 시뮬레이터

## 만들고 싶은 이유

전화번호가 차단되었을 때 발신자가 차단 여부를 쉽게 인지하는 상황에 관심이 생겨 시작했습니다. 
기존 통화 차단 방식은 짧은 통화음 후 음성사서함으로 연결되어 발신자에게 모호한 느낌을 줍니다. 
실제 통신망을 건드리지 않고, 가상의 통화 환경을 시뮬레이션하여 일정 횟수 통화음 반복 후 음성사서함으로 연결되는 등의 다양한 연결 상황을 직접 구현하고 사용자 인식 차이를 확인해 보고자 만들게 되었습니다.

## 예상 사용자

- 차단 사실을 비대면으로 명확히 전달하고 싶은 수신자
- 전화 통화 기반 고객지원 및 영업 관리자
